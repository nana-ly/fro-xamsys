# AI 辅助智能考试与学习平台（Frontend）

基于 Vue3 开发的智能考试学习平台前端项目。

本项目面向教师教学管理和学生考试学习场景，实现教师端、学生端以及公共页面交互，通过前后端分离架构与后端服务进行数据通信。


---

# 项目介绍

AI 辅助智能考试与学习平台是一套面向教育考试场景设计的在线学习系统。

项目包含：

- 学生端
- 教师端
- 管理端

围绕考试学习流程，实现：

- 用户登录注册
- 班级管理
- 题库管理
- 在线考试
- 成绩查看
- 错题复习
- AI 辅助答疑


整体业务流程：

```
教师创建题目/试卷

        ↓

发布考试任务

        ↓

学生完成考试

        ↓

查看考试结果

        ↓

错题复习与 AI 辅助学习
```

# 项目优化记录


## 1. 双端页面体验统一


### 初始问题

项目开发初期，教师端和学生端分别开发。

存在：

- 页面风格不一致
- 登录入口混乱
- 用户操作路径不同


### 优化方案

重新设计：

- 首页结构
- 登录注册流程
- 角色选择入口
- 页面视觉规范


统一教师端和学生端整体体验。


---

## 2. 前端路由优化


### 初始问题

不同角色页面路由存在混用问题。

例如：

- 学生登录后可能进入教师端页面
- 不同角色页面访问边界不清晰


### 优化方案

重新梳理路由结构：

```
公共页面

    ↓

用户身份判断

    ↓

学生端 / 教师端
```


实现不同角色页面隔离。

# AI 功能


## AI 智能出题


前端负责：

- 调用 AI 生成接口
- 展示生成状态
- 反馈生成进度


针对 AI 批量生成等待时间较长的问题：

优化为：

```
一次生成多题

        ↓

逐题生成

        ↓

实时显示生成进度
```


例如：

```
已生成 1/5

已生成 2/5

生成完成
```


提升用户等待过程中的可感知性。
